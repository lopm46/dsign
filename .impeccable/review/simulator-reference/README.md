# Analyse du simulateur Kovan

Source : https://kovan.fr/simulator, consultée et parcourue le 5 novembre 2026.

Onze domaines et 61 services vérifiés un par un dans l’interface. Les sélections de domaines et de services sont multiples ; les services sont réunis dans l’ordre de choix des domaines. Tous les domaines rejoignent les mêmes quatre budgets, quatre délais et formulaire de coordonnées. Aucun calcul de montant ni question de surface n’apparaît. Le formulaire comporte sept coordonnées et une case d’opt-in email facultative. La confirmation du code public prévoit un remerciement et un retour à l’accueil au bout de dix secondes. Aucune soumission n’a été faite à la référence.

`catalogue.json` enregistre les données publiques observées, l’URL et l’empreinte du module public chargé par la référence. `journeys.json` consigne les onze listes réellement parcourues, les écrans communs et les champs du formulaire. Les captures start, multiple-services, budget, timeline et contact servent de références de parcours. Aucun code d’interface propriétaire n’est livré ou réutilisé dans le module D-SIGN.
