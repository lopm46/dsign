# Exploration V2 — revue et captures

Date : 3 novembre 2026. Portée : comparaison visuelle du premier écran, des premiers services et du contact, pas recette d’un thème WordPress en production.

## Contrôles du rendu

- 15 contrôles navigateur : trois pistes à 320, 390, 768, 1024 et 1440 CSS px.
- Aucune largeur de page débordante constatée dans ces contrôles ; aucune image ou police manquante et aucune erreur réseau ou JavaScript détectée.
- Menus mobiles : ouverture et fermeture Escape vérifiées pour les trois pistes à 390 px.
- Comparateur à 390 px : absence de débordement, bouton de sélection et message de choix vérifiés.
- Ancres locales vérifiées ; le bouton « Retenir » ne transmet pas un message et ne déclenche aucun envoi externe.
- Le HTML contient un H1 de document, des IDs uniques, neuf images avec alternatives dont trois occurrences du SVG officiel. Le SVG conserve son empreinte de référence.
- Paires principales de couleurs mesurées : texte clair/charbon 13,22:1 ; accent terre/charbon 8,10:1 ; blanc/vert 6,36:1 ; bleu/papier 8,44:1 ; rose/papier 5,06:1 ; encre/fond rose 7,64:1. Ces contrôles ciblés ne constituent pas une certification WCAG de production.

## Revue indépendante

Les six premières captures ont été examinées sans lecture du code ni de l’historique justificatif. Trois corrections ont été regroupées : entrées explicites des deux publics et vue professionnelle agrandie dans A ; missions remontées dans toutes les introductions ; index redondant supprimé et titre réduit dans C. Les recadrages professionnels ont été remontés pour conserver les toitures.

Les six captures finales ont été recapturées et ouvertes. La passe de vérification indépendante juge les trois écarts **résolus pour l’exploration**, et les directions **présentables pour un choix d’orientation**. Ce verdict ne valide ni un formulaire connecté ni une homepage complète de production.
